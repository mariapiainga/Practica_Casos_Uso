# Práctica de casos de uso – Web Asociación Matrices

Análisis de requisitos de la web de la Asociación Cultural y de Artes Escénicas Matrices (Tres Cantos), basado en un proyecto previo trabajado con Scrum.

## Contenido
- **CU-1 Login**: inicio de sesión, recuperar contraseña y registro.
- **CU-2 Inscripción en evento**: formulario de inscripción con validación de datos.
- **CU-3 Consultar calendario**: visualización de actividades mensuales.

Cada caso incluye descripción textual (actores, precondiciones, curso normal, alternativas y postcondiciones) y su diagrama UML.

## Herramientas
UML · draw.io

## Contexto
Práctica del módulo Entornos de Desarrollo, 1º DAM.
